Política de privacidade

App "O Brasil no Mapa - publicador" · atualizada em 16 de outubro de 2026

Quem usa o app

O app é usado só pelo dono do canal O Brasil no Mapa, para gerenciar o próprio canal. Ele não é oferecido ao público e não tem cadastro de outros usuários.

O que o app acessa

Com a autorização do dono do canal, o app usa a API de Dados do YouTube para enviar vídeos, definir título, descrição, miniatura, legendas e data de publicação, e para ler a lista de vídeos e as estatísticas do próprio canal.

O que o app não faz

  • Não coleta, vende nem compartilha dados de outras pessoas.
  • Não acessa dados de espectadores além das estatísticas agregadas que o YouTube mostra ao dono do canal.
  • Não usa os dados para publicidade.

Armazenamento

O token de autorização fica guardado de forma privada, no ambiente de trabalho do canal, e não é publicado. A autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
